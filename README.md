# SongCatcher

Одна кнопка: слушает музыку через микрофон → распознаёт (AudD) → ищет на YouTube и скачивает звук (yt-dlp) → добавляет в список трека внутри приложения, где его можно проигрывать.

## Как получить APK без Android Studio
1. Создай пустой репозиторий на GitHub, залей туда содержимое этой папки (ветка `main`).
2. Открой вкладку **Actions** → workflow **Build APK** (запустится сам после пуша, или нажми *Run workflow*).
3. Когда сборка позеленеет, открой её и скачай артефакт **songcatcher-debug-apk** (внутри `app-debug.apk`).
4. Установи APK на телефон (разреши установку из неизвестных источников).

## Первый запуск
- Получи бесплатный токен на dashboard.audd.io и вставь в поле в приложении.
- Дай доступ к микрофону, нажми кнопку.

Файлы лежат во внутренней памяти приложения (filesDir/music), список в tracks.json.
