# SongCatcher

Одна кнопка: слушает музыку через микрофон → распознаёт (AudD) → ищет на YouTube и скачивает звук (yt-dlp) → добавляет в список трека внутри приложения, где его можно проигрывать.

## Как получить APK без Android Studio
1. Создай пустой репозиторий на GitHub, залей туда содержимое этой папки (ветка `main`).
2. Открой вкладку **Actions** → workflow **Build APK** (запустится сам после пуша, или нажми *Run workflow*).
3. Когда сборка позеленеет, открой её и скачай артефакт **songcatcher-debug-apk** (внутри `app-debug.apk`).
4. Установи APK на телефон (разреши установку из неизвестных источников).

## Первый запуск
- Получи бесплатный токен на dashboard.audd.io и вставь в поле в приложении.
- Дай доступ к микрофону, нажми кнопку.

Файлы лежат во внутренней памяти приложения (filesDir/music), список в tracks.json.

## v0.4 (кумулятивно после 0.3)
- Экраны: главный (компактный), Настройки (токен AudD, подтверждение видео), Справка.
- Перед скачиванием показывается превью видео, можно выбрать другое и поправить исполнителя/название (отключается в настройках).
- Ручной режим принимает название ролика или ссылку на YouTube; мусор в названиях (Official Video, [4K], #shorts) вычищается.
- Обложка берётся из AudD, а если её нет, то превью видео.
- Переименование треков, меню ⋮ (переименовать / сохранить в Музыку / удалить).
- Ползунок перемотки, повтор (выкл / все / один), shuffle, поиск по трекам.
- Звук телефона: усиление тихой записи, 12 секунд, диагностика в статусе.
- Токен AudD необязателен (без него около 10 запросов в день).
- Распознавание: сначала анонимный запрос, при исчерпании лимита (коды AudD 901/902) используется токен; результат запоминается до конца дня (UTC).
- Иконка приложения.
